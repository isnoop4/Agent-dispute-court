Run a case

A case moves through four actions. The second party must act from a different address than the first.

  1. Create an agreement

    Written by party A. Party B is the other side.

  2. File a dispute

    Either party can file. The evidence link is optional and is read when the ruling is requested.

  3. Respond to a dispute

    Only the other party, not the one who filed, can respond.

  4. Request a ruling

    Either party can request it once a response is in. Validators fetch the evidence and vote, which can take a minute or two.

Runs on GenLayer Studio network. Rulings are recorded by validator consensus and are not legal advice.
