Run a case

A case moves through filing, response and ruling. Safeguards let a claimant withdraw or expire the response window, and either party can appeal once. The second party must act from a different address than the first.

  1. Create an agreement

    Written by party A. Party B is the other side.

    Agreement-specific rules the arbiter must follow when ruling.

    How long the respondent has to answer before the claimant can move the case to ruling.

  2. File a dispute

    Either party can file. Evidence links are optional, up to 3 https links, and are read when the ruling is requested.

    Separate multiple links with a space or comma.

  3. Respond to a dispute

    Only the other party, not the one who filed, can respond.

    Up to 3 https links, separated by a space or comma.

  4. Request a ruling

    Either party can request it once a response is in, or after an appeal. Validators fetch the evidence and vote, which can take a minute or two. A ruling after an appeal is final.

  5. Withdraw, expire, or appeal

    The claimant can withdraw a dispute before it is answered, or expire the response window once it has passed so the case can be ruled without a response. Either party can appeal a ruling once, then request the ruling again for the final decision.

Runs on GenLayer Studio network. Rulings are recorded by validator consensus and are not legal advice.
